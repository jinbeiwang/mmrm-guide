# MMRM 深入理解指南

Mixed Model for Repeated Measures — 从矩阵基础到监管应用

面向临床试验统计程序员与生物统计师的 MMRM 完整学习指南，涵盖：

- 矩阵知识速成
- 线性回归回顾
- MMRM 核心原理
- 协方差结构详解（UN / AR(1) / CS / Toeplitz…）
- 缺失数据与 MAR 假设
- REML 估计与 Kenward–Roger 推断
- 数值示例
- ICH E9(R1) 估计目标框架
- 监管视角（FDA / EMA）
- 软件实现（SAS PROC MIXED / R mmrm）
- 结果解读与常见误区
